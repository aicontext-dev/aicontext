# aicontext

> Open format standard for AI coding assistant project context.
> One source of truth. Every AI tool.

**Specification and tooling — work in progress.**
⭐ Watch/Star this repo for updates.

## What is this?

`.aicontext/` is an open directory format for storing structured
project knowledge that AI coding assistants can use.

Works with: GitHub Copilot · Cursor · Claude Code · Windsurf · Aider

## How to use schema

Use the canonical schema URL in your `.aicontext/context.json`:

```json
{
  "$schema": "https://aicontext.dev/schema/v1/context.schema.json",
  "specVersion": "0.1.0",
  "project": {
    "name": "my-project"
  }
}
```

Then validate locally:

```powershell
.\scripts\validate-aicontext.ps1
```

## CLI (MVP)

Install as a .NET tool:

```powershell
dotnet tool install --global AIContext.CLI
```

Update:

```powershell
dotnet tool update --global AIContext.CLI
```

Run:

```powershell
aicontext --help
```

Quickstart:

```powershell
aicontext init --name my-project
aicontext validate
aicontext export --target all
```

Note:
- `validate` checks `context.json` against the JSON Schema embedded in the tool (the same schema as [schema/v1/context.schema.json](./schema/v1/context.schema.json)), warns about missing or empty recommended files (`architecture.md`, `decisions.md`, `constraints.md`), reports whether the repository meets the Core or Extended profile, and scans `.aicontext/` for common secret patterns (private keys, cloud/API tokens, hard-coded passwords, credentials in URLs; the secret value is never printed). Add `aicontext:allow-secret` to a line to mark an intentional example. Use `--strict` to treat warnings as errors (useful in CI).
- `export --target all` uses `exports.targets` from `.aicontext/context.json` when configured.
- `export` only overwrites files that carry the `Auto-generated by aicontext export` header. Any other existing file is reported as a conflict and nothing is written unless you pass `--force`.
- `export` output is deterministic (LF line endings, no timestamp; a `Source-hash` in the header identifies the sources), so unchanged sources never produce a diff. Unchanged files are not rewritten.
- `--dry-run` shows what would change; `--check` does the same and exits with code 1 when exports are missing or out of date (useful in CI).

Current commands:

- `aicontext init [--path <directory>] [--name <project-name>] [--force]`
- `aicontext validate [--path <directory>] [--strict]`
- `aicontext export --target <agents|copilot|claude|cursor|windsurf|aider> [--path <directory>] [--force] [--dry-run] [--check]`
- `aicontext export --target all [--path <directory>] [--force] [--dry-run] [--check]` (generates targets from `exports.targets`; if not set, generates all supported targets)
